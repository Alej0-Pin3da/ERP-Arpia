# Instrucciones de Proyecto y Agente

## Regla de Documentación de Cambios (V3)
- Cada vez que se realice un cambio, nueva funcionalidad, ajuste de lógica, nuevo componente o modificación en la aplicación a partir de la Versión 3 (V3), **se debe registrar y documentar inmediatamente en el archivo `CambiosV3.md`**.
- El registro debe incluir: fecha, módulo/archivos modificados y una descripción clara y estructurada de lo implementado.
